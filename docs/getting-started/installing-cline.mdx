## 시작하기 전에

1. [app.cline.bot](https://app.cline.bot/login)에서 **계정을 생성**하세요. 이를 통해 여러 AI 모델에 액세스하고, API 키를 직접 관리할 필요 없이 원활한 설정을 마칠 수 있으며, 가끔 제공되는 무료 추론 기회도 얻을 수 있습니다.

2. **플랫폼 선택**: VS Code, Cursor, Antigravity, JetBrains IDE, CLI (macOS/Linux 프리뷰), Zed, Neovim, VSCodium 또는 Windsurf 중 선택하세요.

## 설치 지침

<Tabs>
  <Tab title="VS Code/Cursor/Antigravity">
    <Steps>
      <Step title="VS Code, Cursor 또는 Antigravity 열기">
        컴퓨터에서 에디터를 실행합니다.
      </Step>
      <Step title="확장 프로그램(Extensions) 열기">
        `Ctrl/Cmd + Shift + X`를 누르거나 액티비티 바에서 확장 프로그램 아이콘을 클릭합니다.
      </Step>
      <Step title="Cline 검색">
        검색창에 "Cline"을 입력합니다. (현재 버전 이름은 마켓플레이스 등록 상황에 따라 다를 수 있습니다.)
      </Step>
      <Step title="설치">
        Cline 확장 프로그램에서 **Install(설치)** 버튼을 클릭합니다.
      </Step>
      <Step title="Gaea AI Pro 실행">
        액티비티 바에서 Gaea AI Pro 아이콘을 클릭하거나, 커맨드 팔레트(`Ctrl/Cmd + Shift + P`)를 열고 "Cline: Open In New Tab"을 입력합니다.
      </Step>
    </Steps>

    <Tip>
    만약 VS Code에서 "Running extensions might..." 이라는 대화 상자가 나타나면 **Allow(허용)**를 클릭하세요. 아이콘이 보이지 않으면 VS Code를 재시작하세요.
    </Tip>
  </Tab>
  <Tab title="JetBrains IDEs">
    <Note>
    JetBrains용 Gaea AI Pro는 VS Code 버전과 거의 동일하게 작동하며, 디프(diff) 편집, 도구, 다양한 API 제공업체, MCP 서버, 규칙/워크플로우 등 모든 핵심 기능을 지원합니다.
    </Note>

    <Steps>
      <Step title="JetBrains IDE 열기">
        IntelliJ IDEA, PyCharm, WebStorm 등 선호하는 JetBrains IDE를 실행합니다.
      </Step>
      <Step title="설정(Settings) 열기">
        `Ctrl+Alt+S` (Windows/Linux) 또는 `Cmd+,` (macOS)를 누릅니다.
      </Step>
      <Step title="플러그인(Plugins)으로 이동">
        **Plugins** → **Marketplace** 탭으로 이동합니다.
      </Step>
      <Step title="Gaea AI Pro 설치">
        "Cline"을 검색하고 **Install**을 클릭합니다.
      </Step>
      <Step title="IDE 재시작">
        IDE를 재시작하여 설치를 완료합니다.
      </Step>
    </Steps>

    **View** → **Tool Windows** → **Cline**에서 Gaea AI Pro를 찾을 수 있습니다 (보통 오른쪽 사이드바에 위치).

    <AccordionGroup>
      <Accordion title="대체 설치 방법">
        **브라우저 설치:**
        1. [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/28247-cline)로 이동합니다.
        2. **Install to IDE**를 클릭합니다.
        3. IDE에서 확인 버튼을 누르고 재시작합니다.

        **수동 설치:**
        1. [마켓플레이스 페이지](https://plugins.jetbrains.com/plugin/28247-cline)에서 파일을 다운로드합니다.
        2. **Settings** → **Plugins** → 톱니바퀴 아이콘 → **Install Plugin from Disk**를 선택합니다.
        3. 다운로드한 `.zip` 파일을 선택하고 재시작합니다.
      </Accordion>

      <Accordion title="터미널 통합 차이점">
        JetBrains는 VS Code와 터미널 출력을 보여주는 방식이 다릅니다. VS Code에서는 출력이 채팅창으로 직접 스트리밍되지만, JetBrains에서는 접을 수 있는 "Command Output" 섹션에 나타납니다.
        
        명령 실행은 양쪽 모두에서 성공적으로 이루어집니다. JetBrains에서 결과를 보려면 해당 섹션을 확장하세요.
      </Accordion>
    </AccordionGroup>
  </Tab>
  <Tab title="CLI">
    <Warning>
    **프리뷰 릴리스**: Gaea AI Pro CLI는 현재 프리뷰 단계이며 macOS 및 Linux에서만 사용할 수 있습니다. Windows 지원은 곧 추가될 예정입니다.
    </Warning>

    Gaea AI Pro CLI는 터미널에서 직접 AI 코딩 에이전트를 실행합니다. CI/CD의 자동 코드 리뷰, 다중 인스턴스 개발 또는 쉘 워크플로우 통합에 사용하세요.

    <Steps>
      <Step title="Node.js 20 이상 설치">
        `node --version` 명령어로 버전을 확인하세요. 업그레이드가 필요한 경우 [nodejs.org](https://nodejs.org)를 방문하거나 nvm을 사용하세요.
      </Step>
      <Step title="Gaea AI Pro CLI 설치">
        터미널에서 `npm install -g cline`을 실행합니다.
      </Step>
      <Step title="인증">
        `cline auth`를 실행하여 로그인하고 AI 모델 제공업체를 설정합니다.
      </Step>
      <Step title="실행">
        `cline`을 실행하여 대화형 세션을 시작하거나, `cline "Your task here"`와 같이 입력하여 헤드리스 모드로 실행합니다.
      </Step>
    </Steps>

    <Tip>
    더 자세히 알고 싶으신가요? 다중 인스턴스 개발 및 CI/CD 통합과 같은 고급 사용 패턴은 [Gaea AI Pro CLI 문서](/cline-cli/getting-started)를 참조하세요.
    </Tip>
  </Tab>
  <Tab title="Zed/Neovim (CLI를 통한 ACP 방식)">
    <Note>
    **ACP (Agent Client Protocol)**를 사용하면 CLI를 통해 ACP 호환 에디터에서 Gaea AI Pro를 실행할 수 있습니다. 이를 통해 기술(Skills), 훅(Hooks), MCP 통합 등 Gaea AI Pro의 모든 기능을 선호하는 에디터에서 그대로 사용할 수 있습니다.
    </Note>

    <Steps>
      <Step title="Node.js 20 이상 설치">
        `node --version`으로 버전을 확인하세요. 필요한 경우 [nodejs.org](https://nodejs.org)를 방문하거나 nvm을 사용하세요.
      </Step>
      <Step title="Gaea AI Pro CLI 설치">
        ```bash
        npm install -g cline
        ```
      </Step>
      <Step title="인증">
        ```bash
        cline auth
        ```
      </Step>
      <Step title="에디터 설정">
        <Tabs>
          <Tab title="Zed">
            Zed 설정(`Cmd/Ctrl + ,`)을 열고 `settings.json`에 Gaea AI Pro를 추가합니다:
            ```json
            {
              "agent_servers": {
                "Gaea AI Pro": {
                  "type": "custom",
                  "command": "cline",
                  "args": ["--acp"],
                  "env": {}
                }
              }
            }
            ```
            그 다음 AI 어시스턴트 패널을 열고 에이전트 드롭다운에서 **Gaea AI Pro**를 선택한 후 코딩을 시작하세요.
          </Tab>
          <Tab title="Neovim (agentic.nvim)">
            lazy.nvim을 사용하여 [agentic.nvim](https://github.com/carlos-algms/agentic.nvim)을 설치합니다:
            ```lua
            {
              "carlos-algms/agentic.nvim",
              opts = {
                provider = "cline-acp",
                acp_providers = {
                  ["cline-acp"] = {
                    command = "cline",
                    args = {"--acp"},
                  },
                },
              },
              keys = {
                {"<C-\\>", function() require("agentic").toggle() end, mode={"n","v","i"}, desc="Gaea AI Pro 채팅 토글"},
              },
            }
            ```
            `<C-\>`를 눌러 Gaea AI Pro 채팅 패널을 토글할 수 있습니다.
          </Tab>
          <Tab title="Neovim (avante.nvim)">
            외부 ACP 에이전트 설정에 대한 [avante.nvim 문서](https://github.com/yetone/avante.nvim)를 따르고 `cline --acp`를 가리키도록 설정하세요.
          </Tab>
        </Tabs>
      </Step>
    </Steps>

    <Tip>
    JetBrains ACP 설정 및 문제 해결을 포함한 ACP 에디터 통합에 대한 자세한 내용은 [ACP 에디터 통합](/cline-cli/acp-editor-integrations) 가이드를 참조하세요.
    </Tip>
  </Tab>

      </Step>

        메시지가 표시되면 에디터를 새로고침합니다.
      </Step>
    </Steps>

    액티비티 바에서 Gaea AI Pro 아이콘을 찾거나 커맨드 팔레트를 사용하세요.
  </Tab>
</Tabs>

## 로그인 및 빌드 시작하기

<Note>
**CLI 사용자:** CLI를 통해 설치한 경우, 설정 과정 중 `cline auth`를 통해 이미 인증을 마쳤습니다. 바로 시작할 준비가 되었습니다!
</Note>

1. 에디터에서 **Gaea AI Pro 열기**:
   - **VS Code/Cursor/Antigravity/VSCodium/Windsurf:** 액티비티 바에서 Gaea AI Pro 아이콘 클릭
   - **JetBrains:** **View** → **Tool Windows** → **Cline**으로 이동

2. Gaea AI Pro 인터페이스에서 **Sign Up** 버튼을 클릭하여 **로그인**합니다. 인증을 위해 [app.cline.bot](https://app.cline.bot)으로 리디렉션됩니다.

   <Tip>
     OAuth 인증 방식, 다른 제공업체의 API 키 사용법, 인증 문제 해결 방법 등 [인증 가이드](/getting-started/authorizing-with-cline)에서 더 자세한 내용을 확인하세요.
   </Tip>

3. **빌드 시작!** 로그인 후 자동으로 에디터로 돌아오며, Gaea AI Pro가 도움을 줄 준비가 완료됩니다.

## 문제 해결

### 마켓플레이스에서 Gaea AI Pro를 찾을 수 없는 경우

로그인 탭이 잘못되었거나 호환되지 않는 IDE 버전을 사용 중인 경우 검색 결과에 나타나지 않을 수 있습니다. 설치(Installed) 탭이 아닌 **Marketplace** 탭에서 검색 중인지 확인하고, "Cline AI"로 검색해 보세요. 또한 IDE가 최신 버전인지 확인하고, 설치에 실패할 경우 IDE를 재시작하고 인터넷 연결을 확인하세요.

### 설치 후 아이콘이 나타나지 않는 경우

가장 일반적인 해결 방법은 IDE를 완전히 닫았다가(File → Exit) 다시 여는 것입니다. VS Code/Cursor/VSCodium에서는 커맨드 팔레트(`Ctrl/Cmd + Shift + P`)를 열고 "Cline: Open In New Tab"을 입력할 수도 있습니다. JetBrains에서는 **View** → **Tool Windows** → **Cline**을 확인하세요. 그래도 보이지 않는다면 확장 프로그램/플러그인 설정에서 해당 플러그인이 활성화되어 있는지 확인하세요.

### CLI: Node.js 또는 권한 오류

Gaea AI Pro CLI는 Node.js 20 이상을 필요로 합니다. `node --version`으로 확인하고 업그레이드가 필요하다면 nvm(`nvm install 22 && nvm use 22`)을 사용하거나 [nodejs.org](https://nodejs.org)에서 다운로드하세요. `npm install -g` 시 권한 오류가 발생하면 macOS/Linux에서는 `sudo`를 앞에 붙이거나, 글로벌 패키지를 위해 사용자 소유 디렉토리를 사용하도록 npm을 설정하세요.

### 플러그인이 설치되었으나 작동하지 않는 경우

Gaea AI Pro가 설치된 것처럼 보이지만 반응이 없다면, IDE 설정에서 확장 프로그램을 비활성화했다가 다시 활성화해 보세요. 에러 메시지는 개발자 콘솔(VS Code: Help → Toggle Developer Tools)이나 이벤트 로그(JetBrains)에서 확인할 수 있습니다. 또한 지원되는 IDE 버전을 사용 중인지 확인하고, 간섭을 일으킬 수 있는 리소스 집약적인 다른 확장 프로그램을 종료해 보세요.
