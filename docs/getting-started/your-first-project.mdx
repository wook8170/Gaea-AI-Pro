이 튜토리얼에서는 Gaea AI Pro와 함께 처음부터 할 일(Todo) 앱을 만드는 과정을 안내합니다. 과정을 통해 작업을 부여하고, 변경 사항을 승인하고, 결과물을 개선하며, 실수를 복구하는 방법을 배우게 됩니다.

**예상 소요 시간:** 5-10분

## 사전 준비

시작하기 전에 다음 사항을 확인하세요:

- 에디터에 Gaea AI Pro가 설치되어 있어야 함 ([설치 가이드](/getting-started/installing-cline))
- AI 모델이 연결되어 있어야 함 ([모델 설정](/getting-started/authorizing-with-cline))

아직 준비가 되지 않았다면 먼저 완료하고 다시 돌아와 주세요.

## 1단계: 프로젝트 폴더 열기

Gaea AI Pro는 파일을 생성하고 편집할 수 있는 작업 공간(컴퓨터의 폴더)이 필요합니다. Gaea AI Pro가 할 일 앱을 구축할 수 있도록 빈 폴더를 열어보겠습니다.

<Tabs>
  <Tab title="VS Code / Cursor / Windsurf">
    1. 상단 메뉴 바에서 **File → Open Folder**를 선택합니다.
    2. 컴퓨터에 새 폴더를 만듭니다 (예: 바탕화면에 `todo-app`이라는 이름으로 생성).
    3. 해당 폴더를 선택하고 **Open**을 클릭합니다.

    이제 에디터 왼쪽 사이드바 상단에 폴더 이름이 표시될 것입니다. 새 폴더이므로 파일 탐색기(왼쪽 패널)는 비어 있습니다.
  </Tab>
  <Tab title="JetBrains">
    1. 상단 메뉴 바에서 **File → Open**을 선택합니다.
    2. 컴퓨터에 새 폴더를 만듭니다 (예: 바탕화면에 `todo-app`이라는 이름으로 생성).
    3. 해당 폴더를 선택하고 **OK**를 클릭합니다.

    이제 에디터 왼쪽의 프로젝트 패널에 폴더 이름이 표시될 것입니다. 새 폴더이므로 아무것도 보이지 않습니다.
  </Tab>
</Tabs>

<Warning>
이 단계를 건너뛰고 폴더를 열지 않으면 Gaea AI Pro가 어디에 파일을 만들어야 할지 알 수 없습니다. 작업을 시작하기 전에는 항상 폴더를 먼저 열어주세요.
</Warning>

## 2단계: Gaea AI Pro 패널 열기

Gaea AI Pro 패널은 여러분이 Gaea AI Pro와 대화하는 채팅 인터페이스입니다. 지시를 내리기 전에 이 패널을 열어야 합니다.

<Tabs>
  <Tab title="VS Code / Cursor / Windsurf">
    에디터의 맨 왼쪽(또는 오른쪽)에 있는 아이콘 띠인 **액티비티 바**를 확인하세요. **Gaea AI Pro 아이콘**(작은 로봇 모양)을 찾아 클릭합니다.

    Gaea AI Pro 채팅 인터페이스 패널이 열립니다. 다음 항목들을 확인할 수 있습니다:
    - 맨 아래: 메시지를 입력하는 **텍스트 입력창**
    - 위쪽: Gaea AI Pro의 응답이 표시되는 **채팅 영역**
    - 오른쪽 위: **설정 아이콘**(톱니바퀴 모양)

    <Tip>
    **아이콘을 찾을 수 없나요?** `Cmd+Shift+P` (Mac) 또는 `Ctrl+Shift+P` (Windows/Linux)로 커맨드 팔레트를 열고 **"Cline: Open In New Tab"**을 입력한 후 Enter를 누르세요. 이렇게 하면 Gaea AI Pro가 전체 에디터 탭으로 열려 더 넓은 화면에서 작업할 수 있습니다.
    </Tip>
  </Tab>
  <Tab title="JetBrains">
    상단 메뉴 바에서 **View → Tool Windows → Cline**을 선택합니다. 에디터 오른쪽에 Gaea AI Pro 패널이 열립니다.

    다음 항목들을 확인할 수 있습니다:
    - 맨 아래: 메시지를 입력하는 **텍스트 입력창**
    - 위쪽: Gaea AI Pro의 응답이 표시되는 **채팅 영역**
    - 오른쪽 위: **설정 아이콘**(톱니바퀴 모양)
  </Tab>
</Tabs>

## 3단계: Gaea AI Pro에게 작업 부여하기

이제 무엇을 만들지 지시해 보겠습니다. 채팅 앱을 사용하는 것처럼 텍스트 입력창에 메시지를 입력하여 소통합니다.

1. Gaea AI Pro 패널 하단의 **텍스트 입력창을 클릭**합니다.
2. 입력창에 **아래 프롬프트를 복사(또는 입력)**합니다:

```text
단일 HTML 파일로 할 일(Todo) 앱을 만들어줘. 다음을 포함해야 해:
- 새로운 작업을 추가하는 입력 필드
- 모든 작업을 보여주는 목록
- 작업 완료를 표시하는 체크박스 (취소선 스타일 적용)
- 개별 작업을 삭제하는 버튼
- CSS를 사용한 깔끔하고 현대적인 디자인
- 모든 자바스크립트는 같은 파일 안에 인라인으로 작성
```

3. 키보드의 **Enter**를 누르거나 **보내기(Send)** 버튼을 클릭하여 메시지를 전송합니다.

Gaea AI Pro가 메시지를 읽고 응답을 준비하기 시작합니다. Gaea AI Pro가 요청을 분석하는 동안 채팅 영역에 텍스트가 나타나는 것을 볼 수 있습니다.

## 4단계: 계획 모드 vs 실행 모드 이해하기

Gaea AI Pro가 작업을 받으면 두 가지 모드 중 하나로 시작할 수 있습니다. Gaea AI Pro 패널 하단을 보시면 **"계획(Plan)"** 또는 **"실행(Act)"**이라고 적힌 토글 버튼이 있습니다.

### 계획(Plan) 모드인 경우

계획 모드에서 Gaea AI Pro는 **대화만** 합니다. 요청을 분석하고 접근 방식에 대해 논의하지만, 파일을 생성하거나 수정하지는 않습니다. 어떤 것을 만들지 설명하는 것을 볼 수 있지만, 프로젝트 폴더에는 아직 아무런 변화도 생기지 않습니다.

이 모드는 접근 방식을 먼저 논의하고 싶은 복잡한 작업에 유용합니다. 다음과 같은 작업을 할 수 있습니다:
- 계획에 대해 질문하기
- 접근 방식에 대한 수정 제안
- 요구 사항 구체화하기

**Gaea AI Pro가 코드를 작성하기 시작하게 하려면**, 패널 하단의 토글 버튼을 클릭하여 **"계획"**에서 **"실행"**으로 전환하세요. 그러면 실제 파일 변경 사항을 제안하기 시작합니다.

### 실행(Act) 모드인 경우

실행 모드에서 Gaea AI Pro는 바로 파일을 생성하고 코드를 작성하기 시작합니다 (하지만 여전히 변경하기 전에 여러분의 승인을 먼저 구합니다. 다음 단계를 참조하세요).

<Note>
이 튜토리얼에서는 Gaea AI Pro가 할 일 앱을 직접 만들어야 하므로 **실행(Act) 모드**여야 합니다. 하단에 "계획"이 보인다면 클릭하여 "실행"으로 전환하세요. 각 모드의 활용 시점은 [계획 및 실행 가이드](/core-workflows/plan-and-act)에서 자세히 알아볼 수 있습니다.
</Note>

## 5단계: 변경 사항 승인하기

Gaea AI Pro는 여러분의 허락 없이 파일을 **절대** 수정하지 않습니다. 파일을 생성하거나 수정하기 전에 Gaea AI Pro는 무엇을 하려는지 정확히 보여주고 여러분이 승인할 때까지 기다립니다.

채팅창에서 다음을 확인하게 됩니다:

1. **Gaea AI Pro가 파일 변경을 제안합니다.** 파일 경로(예: `index.html`)와 작성하려는 코드가 채팅창에 표시됩니다. 새로운 코드는 **초록색**으로 강조됩니다.

2. **Approve(승인) 또는 Reject(거절) 버튼이 나타납니다.** 제안된 변경 사항 바로 아래에 두 개의 버튼이 보입니다:
   - **Approve** (체크 표시): Gaea AI Pro가 파일을 생성하거나 수정할 수 있게 허용합니다. 파일이 프로젝트 폴더에 저장됩니다.
   - **Reject** (X 표시): Gaea AI Pro의 작업을 중단하고 다른 지시를 내립니다.

3. **Approve를 클릭**하여 `index.html` 파일을 생성하게 합니다.

승인하고 나면 Gaea AI Pro가 프로젝트 폴더에 파일을 기록합니다. 에디터의 파일 탐색기(왼쪽 패널)에 `index.html`이 나타나는 것을 볼 수 있습니다.

<Note>
모든 파일 생성, 수정 및 터미널 명령어 실행에는 여러분의 명시적인 승인이 필요합니다. 프로젝트에 무엇이 바뀌는지는 항상 여러분이 제어합니다. 사용이 익숙해지면 [자동 승인(auto-approve)](/features/auto-approve) 기능을 활성화하여 특정 작업에 대한 확인 단계를 건너뛸 수도 있습니다.
</Note>

## 6단계: 완성된 앱 확인하기

Gaea AI Pro가 프로젝트 폴더에 `index.html` 파일을 만들었습니다. 이제 웹 브라우저에서 열어 확인해 보겠습니다.

<Tabs>
  <Tab title="macOS">
    **방법 A: 터미널 사용**

    에디터에서 터미널을 열고 (`` Ctrl+` `` 또는 메뉴에서 **Terminal → New Terminal**) 다음을 입력하세요:
    ```bash
    open index.html
    ```

    **방법 B: Finder 사용**

    에디터의 파일 탐색기(왼쪽 패널)에서 `index.html`을 마우스 오른쪽 버튼으로 클릭하고 **"Reveal in Finder"**를 선택합니다. 그 다음 Finder에서 파일을 더블 클릭하여 브라우저로 엽니다.
  </Tab>
  <Tab title="Windows">
    **방법 A: 터미널 사용**

    에디터에서 터미널을 열고 (`` Ctrl+` `` 또는 메뉴에서 **Terminal → New Terminal**) 다음을 입력하세요:
    ```bash
    start index.html
    ```

    **방법 B: 파일 탐색기 사용**

    에디터의 파일 탐색기(왼쪽 패널)에서 `index.html`을 마우스 오른쪽 버튼으로 클릭하고 **"Reveal in File Explorer"**를 선택합니다. 그 다음 파일을 더블 클릭하여 브라우저로 엽니다.
  </Tab>
  <Tab title="Linux">
    **방법 A: 터미널 사용**

    에디터에서 터미널을 열고 (`` Ctrl+` `` 또는 메뉴에서 **Terminal → New Terminal**) 다음을 입력하세요:
    ```bash
    xdg-open index.html
    ```

    **방법 B: 파일 관리자 사용**

    에디터의 파일 탐색기(왼쪽 패널)에서 `index.html`을 마우스 오른쪽 버튼으로 클릭하고 **"Open Containing Folder"**를 선택합니다. 그 다음 파일을 더블 클릭하여 브라우저로 엽니다.
  </Tab>
</Tabs>

**방법 C: Live Server (모든 OS 공통)**

VS Code에 Live Server 확장 프로그램이 설치되어 있다면, 파일 탐색기에서 `index.html`을 오른쪽 클릭하고 **"Open with Live Server"**를 선택하세요. 브라우저에서 앱이 열리고 파일이 바뀔 때마다 자동으로 새로고침됩니다.

완성된 할 일 앱을 테스트해 보세요: 할 일을 추가하고, 체크해보고, 삭제해 보세요. 서버나 백엔드 없이 전적으로 브라우저에서만 실행되는 앱입니다.

## 7단계: 프로젝트 개선하기

Gaea AI Pro의 가장 강력한 기능 중 하나는 전체 대화 내용을 기억한다는 점입니다. 처음부터 다시 시작할 필요 없이 변경을 요청하면 기존 코드를 수정해 줍니다.

**기존 채팅창에서** (새로 시작하지 말고) 하단의 입력창에 추가 요청을 입력해 보세요. 예를 들어 다음과 같은 요청이 가능합니다:

**데이터 저장 기능 추가:**
```text
페이지를 새로고침해도 작업 내용이 유지되도록 로컬 스토리지를 추가해줘
```

**디자인 변경:**
```text
보라색 포인트를 준 다크 테마로 바꿔줘
```

**기능 추가:**
```text
전체, 진행 중, 완료된 작업을 골라낼 수 있는 필터를 추가해줘
```

추가 메시지를 보내면 Gaea AI Pro는:
1. 기존 코드를 이해하기 위해 현재 `index.html` 파일을 읽습니다.
2. 특정 변경 사항을 제안합니다 (추가된 줄은 초록색, 삭제된 줄은 빨간색으로 표시된 diff 형식).
3. 파일을 수정하기 전에 여러분의 승인을 기다립니다.

**Approve**를 클릭하여 변경 사항을 적용하고, 브라우저를 새로고침하여 업데이트된 앱을 확인하세요.

## 8단계: 체크포인트로 실수 복구하기

Gaea AI Pro는 변경 사항을 적용할 때마다 자동으로 **체크포인트(checkpoint)**를 저장합니다. 무언가 잘못되었거나 수정 사항이 마음에 들지 않는다면 언제든지 이전 상태로 되돌릴 수 있습니다.

### 체크포인트 찾는 방법

Gaea AI Pro 패널의 대화 내용을 스크롤하여 위로 올려보세요. 변경이 일어난 각 단계 옆에 두 개의 작은 버튼이 있습니다:

- **Compare (비교)**: 해당 단계에서 어떤 파일이 변경되었는지 정확히 확인합니다 (전/후 비교).
- **Restore (복구)**: 프로젝트를 해당 시점의 상태로 되돌립니다.

### 복구 방법

**Restore**를 클릭하면 세 가지 옵션이 나타납니다:

| 옵션 | 수행 내용 | 활용 시점 |
|--------|--------------|----------------|
| **Restore Task and Workspace** | 파일과 대화 내용을 모두 해당 시점으로 초기화 | 완전히 뒤로 돌아가서 그 단계부터 다시 시작하고 싶을 때 |
| **Restore Task Only** | 현재 파일은 유지하되 대화 문맥만 되돌림 | 거의 사용되지 않음 |
| **Restore Workspace Only** | 파일은 해당 시점으로 되돌리되 전체 대화 내용은 유지 | 다른 접근 방식을 시도해 보고 싶지만 대화 기록은 남기고 싶을 때 |

**초보자 추천:** 무언가 취소하고 싶지만 Gaea AI Pro와 어떻게 다르게 작업할지 계속 대화하고 싶다면 **"Restore Workspace Only"**를 사용하세요.

<Tip>
체크포인트는 Git과는 별개입니다. 여러분이 설정한 커밋, 브랜치 또는 다른 버전 관리 시스템에는 영향을 주지 않습니다.
</Tip>

더 자세한 내용은 [체크포인트 가이드](/core-workflows/checkpoints)를 참조하세요.

## 학습 내용 요약

방금 Gaea AI Pro의 핵심 워크플로우를 마쳤습니다:

1. Gaea AI Pro가 작업할 수 있도록 **프로젝트 폴더를 열었습니다.**
2. **Gaea AI Pro 패널을 열고** 채팅창에 작업을 입력했습니다.
3. **계획 vs 실행 모드의 차이**와 전환 방법을 이해했습니다.
4. 디스크에 기록하기 전에 **파일 변경 사항을 승인**했습니다.
5. 같은 대화창에서 추가 메시지를 보내 **기능을 개선**했습니다.
6. 실수를 바로잡기 위해 **체크포인트를 사용**했습니다.

이러한 패턴은 간단한 스크립트부터 복잡한 애플리케이션까지 모든 프로젝트에 동일하게 적용됩니다. 원하는 결과에 대해 Gaea AI Pro에게 더 많은 맥락(context)을 제공할수록 더 좋은 결과를 얻을 수 있습니다.
