Gaea AI Pro는 에디터에서 동작하는 오픈 소스 AI 코딩 에이전트입니다. 제한이나 예기치 않은 상황, 모델 생태계에 대한 종속성 없이 최첨단 AI에 직접적이고 투명하게 액세스할 수 있습니다. 모든 결정을 지켜보고, 원하는 모델을 선택하며, 비용을 제어하세요.

<Tip>
  **코딩 에이전트가 처음이신가요?** [코딩 에이전트란 무엇인가요?](https://youtu.be/CYIteJeNcuw) 영상을 통해 Gaea AI Pro가 실제로 어떻게 작동하는지 확인해 보세요.
</Tip>

## Gaea AI Pro의 기능

Gaea AI Pro는 여러분의 승인 하에 코드베이스에서 직접 작동합니다:

- **파일 읽기 및 쓰기** - 코드베이스를 탐색하고, 새 파일을 생성하며, 목표한 부분을 수정합니다. 모든 변경 사항은 실행 전 여러분의 승인을 거칩니다.
- **터미널 명령어 실행** - 쉘 명령을 실행하고, 테스트를 수행하며, 패키지를 설치하고 실시간으로 오류를 디버깅합니다.
- **브라우저 사용** - 웹 앱을 테스트하고, 스크린샷을 캡처하며, 페이지와 상호 작용하기 위해 브라우저를 실행합니다.
- **외부 도구 연결** - 데이터베이스, API 및 문서를 위한 [MCP 서버](/mcp/mcp-overview)로 기능을 확장합니다.
- **명령줄 실행** - 헤드리스 자동화, CI/CD 파이프라인 및 쉘 워크플로우를 위해 [Gaea AI Pro CLI](/cline-cli/getting-started)를 사용합니다.

## 핵심 워크플로우

Gaea AI Pro와 함께 매일 사용하게 될 패턴들입니다:

| 워크플로우 | 기능 설명 |
|----------|--------------|
| [계획 및 실행](/core-workflows/plan-and-act) | 먼저 생각하고, 그 다음에 구축합니다. 계획(Plan) 모드는 변경 없이 코드베이스를 탐색합니다. 실행(Act) 모드는 솔루션을 구현합니다. |
| [작업 관리](/core-workflows/task-management) | 작업을 시작하고, 이전 작업을 재개하며, 장기 실행 세션을 관리합니다. |
| [파일 작업](/core-workflows/working-with-files) | 프롬프트에서 @ 멘션을 사용하여 파일, 폴더, URL 및 터미널 출력을 참조합니다. |
| [명령어](/core-workflows/using-commands) | 키보드 단축키, 슬래시 명령어 및 터미널 통합 기능을 사용합니다. |
| [체크포인트](/core-workflows/checkpoints) | 프로젝트의 자동 스냅샷입니다. 즉시 이전 상태로 복구할 수 있습니다. |

## 왜 Gaea AI Pro인가요?

- **기본적으로 투명함** - 모든 파일 읽기, 고려된 결정, 사용된 토큰을 지켜보세요. 블랙박스가 아닙니다.
- **모든 모델, 모든 제공업체** - Claude, GPT-4, Gemini, DeepSeek 또는 로컬 모델을 사용하세요. 새 모델이 출시되면 즉시 전환할 수 있습니다.
- **제로 트러스트 아키텍처** - 여러분의 코드는 절대 저희 서버에 닿지 않습니다. Gaea AI Pro는 여러분의 API 키를 사용하여 전적으로 클라이언트 측에서 실행됩니다.
- **오픈 소스** - 모든 코드는 [GitHub](https://github.com/cline/cline)에 공개되어 있습니다. 매일 사용하는 개발자들로부터 5만 개 이상의 별을 받았습니다.
