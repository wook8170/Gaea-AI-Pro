## 컨텍스트 윈도우(Context Window)란 무엇인가요?

컨텍스트 윈도우는 AI 모델이 한 번에 처리할 수 있는 최대 텍스트 양을 의미합니다. 모델의 '작업 메모리'라고 생각하면 쉽습니다. 모델이 답변을 생성할 때 현재 대화 내용과 코드를 얼마나 많이 고려할 수 있는지를 결정합니다.

<Note>
**핵심 포인트**: 컨텍스트 윈도우가 클수록 모델이 한 번에 더 많은 코드베이스를 이해할 수 있지만, 비용이 증가하고 응답 시간이 길어질 수 있습니다.
</Note>

## 컨텍스트 윈도우 크기

### 빠른 참조 가이드

| 크기 | 토큰(Tokens) | 대략적인 단어 수 | 주요 사례 |
|------|--------|------------------|----------|
| **소형 (Small)** | 8K-32K | 6,000-24,000 | 단일 파일 수정, 빠른 해결 |
| **중형 (Medium)** | 128K | ~96,000 | 대부분의 코딩 프로젝트 |
| **대형 (Large)** | 200K | ~150,000 | 복잡한 코드베이스 |
| **초대형 (Extra Large)** | 400K+ | ~300,000+ | 애플리케이션 전체 |
| **대규모 (Massive)** | 1M+ | ~750,000+ | 다중 프로젝트 분석 |

### 모델별 컨텍스트 윈도우

| 모델 | 컨텍스트 윈도우 | 유효 윈도우* | 비고 |
|-------|---------------|------------------|-------|
| **Claude Sonnet 4.5** | 1M tokens | ~500K tokens | 고용량 컨텍스트에서 최고의 품질 |
| **GPT-5** | 400K tokens | ~300K tokens | 성능에 영향을 미치는 세 가지 모드 |
| **Gemini 2.5 Pro** | 1M+ tokens | ~600K tokens | 대규모 문서 처리에 탁월 |
| **DeepSeek V3** | 128K tokens | ~100K tokens | 대부분의 작업에 최적화 |
| **Qwen3 Coder** | 256K tokens | ~200K tokens | 우수한 균형 |

*유효 윈도우는 모델이 높은 품질을 유지하는 실제 범위입니다.

## 효율적인 컨텍스트 관리

### 컨텍스트에 포함되는 항목

1. **현재 대화** - 채팅창의 모든 메시지
2. **파일 내용** - 공유했거나 Gaea AI Pro가 읽은 모든 파일
3. **도구 출력** - 실행된 명령어의 결과물
4. **시스템 프롬프트** - Gaea AI Pro의 지침 (영향 미미)

### 최적화 전략

#### 1. 새로운 기능 개발 시 새로 시작하기
```text
/new - 깨끗한 컨텍스트로 새 작업 생성
```
장점:
- 사용 가능한 최대 컨텍스트 확보
- 불필요한 히스토리 제거
- 모델의 집중도 향상

#### 2. @ 멘션(Mentions) 전략적 사용
파일 전체를 포함하는 대신:
- `@filename.ts` - 필요한 경우에만 포함
- 대용량 파일을 읽는 대신 검색 기능 활용
- 파일 전체보다 특정 함수를 참조

#### 3. 자동 압축(Auto-compact) 활성화
Gaea AI Pro는 긴 대화를 자동으로 요약할 수 있습니다:
- 설정(Settings) → 기능(Features) → 자동 압축(Auto-compact)
- 중요한 문맥 보존
- 토큰 사용량 절감

## 컨텍스트 윈도우 경고

### 한계에 도달했다는 신호

| 경고 신호 | 의미 | 해결 방법 |
|-------------|---------------|----------|
| **"Context window exceeded"** | 한계치 도달 | 새 작업 시작 또는 자동 압축 활성화 |
| **응답 속도 저하** | 모델이 컨텍스트 처리에 과부하를 느낌 | 포함된 파일 수 줄이기 |
| **반복적인 제안** | 컨텍스트 파편화 발생 | 요약 후 새 작업으로 시작 |
| **최근 변경 사항 누락** | 컨텍스트 오버플로우 발생 | 체크포인트를 사용해 변경 사항 추적 |

### 프로젝트 크기별 권장 사항

#### 소규모 프로젝트 (파일 50개 미만)
- 모든 모델이 잘 작동함
- 관련 파일을 자유롭게 포함 가능
- 특별한 최적화 불필요

#### 중규모 프로젝트 (파일 50-500개)
- 128K 이상의 컨텍스트 모델 사용 권장
- 현재 작업 중인 파일 세트만 포함
- 기능 구현 사이에 컨텍스트 정리

#### 대규모 프로젝트 (파일 500개 이상)
- 200K 이상의 컨텍스트 모델 사용 권장
- 특정 모듈에 집중
- 많은 파일을 읽는 대신 검색 기능 활용
- 작업을 더 작은 단위로 분할

## 고급 컨텍스트 관리

### 계획(Plan)/실행(Act) 모드 최적화

더 나은 컨텍스트 활용을 위해 계획/실행 모드를 활용하세요:
- **계획(Plan) 모드**: 토론을 위해 더 작은 컨텍스트 사용
- **실행(Act) 모드**: 구현을 위해 필요한 파일들을 포함

설정 예시:
```text
계획(Plan) 모드: DeepSeek V3 (128K) - 비용 효율적인 계획 수립
실행(Act) 모드: Claude Sonnet (1M) - 코딩을 위한 최대 컨텍스트 확보
```

### 컨텍스트 정리(Pruning) 전략

1. **시간적 정리**: 오래된 대화 내용 제거
2. **의미적 정리**: 관련 있는 코드 섹션만 유지
3. **계층적 정리**: 상위 수준 구조는 유지하고 세부 정보만 정리

### 토큰 계산 팁

#### 대략적인 추정치
- **1 토큰 ≈ 단어 0.75개**
- **1 토큰 ≈ 4 글자**
- **코드 100줄 ≈ 500-1000 토큰**

#### 파일 크기 기준 가이드
| 파일 형식 | KB당 토큰 |
|-----------|---------------|
| **코드 (Code)** | ~250-400 |
| **JSON** | ~300-500 |
| **마크다운 (Markdown)** | ~200-300 |
| **일반 텍스트** | ~200-250 |

## 컨텍스트 윈도우 자주 묻는 질문(FAQ)

### Q: 대화가 길어질수록 왜 답변 품질이 떨어지나요?
**A:** 모델이 너무 많은 정보를 가지게 되면 집중력을 잃을 수 있습니다. "유효 윈도우"는 일반적으로 광고된 한계치의 50-70% 정도입니다.

### Q: 항상 사용 가능한 가장 큰 컨텍스트 윈도우를 사용해야 하나요?
**A:** 항상 그렇지는 않습니다. 컨텍스트가 커질수록 비용이 증가하고 응답 품질이 떨어질 수 있습니다. 작업의 크기에 맞는 컨텍스트를 선택하세요.

### Q: 내가 얼마나 많은 컨텍스트를 사용하고 있는지 어떻게 알 수 있나요?
**A:** Gaea AI Pro 인터페이스에 토큰 사용량이 표시됩니다. 컨텍스트 게이지가 한계에 도달하는지 확인하세요.

### Q: 컨텍스트 한계를 초과하면 어떻게 되나요?
**A:** Gaea AI Pro는 다음 중 하나를 수행합니다:
- 대화를 자동으로 압축함 (활성화된 경우)
- 오류를 표시하고 새 작업을 시작하도록 제안함
- 이전 메시지를 잘라냄 (경고와 함께)
